# webxr-threejs-spheres

three.js + WebXR (immersive-vr) の最小動作確認ページ（React + Vite + TypeScript + Tailwind CSS v4）。

- シャボン玉のような透明な球体のまとまり3つが浮遊。通常時は中央の大きな球と、周囲で重なる4つの球で構成。周囲の小球は生成時にサイズ・角度・間隔・距離・奥行きをランダムにし、最大の小球は従来の0.6倍（中央の球に対する基準サイズ0.74→0.444）、残る3つは中央の0.28〜0.4倍にする。小さな球ほど中央に寄せて重なりを保ち、等間隔の十字配置にはしない。規則的な公転はせず、それぞれ異なる周期で風に押されるように前後・内外に漂う。全体の上下動はゆっくりとし、膜がわずかに伸び縮みする。左から `public/assets-2` / `assets-1` / `assets-3` の写真を表示し、1枚目は中央、続く最大4枚は周囲の球に表示。写真の少ない記憶でも5球の形を維持し、6枚目以降もリングと写真の切り替えですべて閲覧できる
- 泡は記憶ごとに淡く色分け。同じ記憶の中心・周りの泡・開いたリングは同系色になり、写真自体の色は変えない。既存の `--sphere` 色から少しずつ色相を変え、半透明の質感を維持する。共有された記憶はIDから色を決めるため、読み込み順・再読み込み・Web／VRの切替でも同じ色になる
- 膜は低い粗さのPhysicalマテリアルと薄膜干渉で表現。中心は透け、縁にはゆっくり流れる虹色と白い三日月状の反射・小さなハイライトが出る。Web／VRとも視線に合わせて反射が変化し、リングにも同じ質感を適用する
- 同じまとまりの泡が接して重なる場合は、初期状態・注視中・分散／復元中・ユーザーの周囲への移動中を問わず、つながった泡全体を一枚の膜で描く。3個以上の連鎖した重なりも同じ面にまとめ、内側の円や重なった二重の膜は表示しない。離れた泡は独立した膜へ戻る。写真と選択用の形状は維持する
- ホバー／VR注視中は大きな泡の内側で小球が育ち、膜が伸びてくびれてから離れる約0.85秒の分裂で、小〜中サイズの7個に分散する。途中はMarching Cubesの連続した膜で描き、単なる円の出現・縮小にはしない。視線やポインターを外すと同じ経路を逆にたどり、膜がつながって融合し、5個のまとまりに戻る。途中で反転しても動きは連続する。写真が少なくても7個を維持し、最大7枚をプレビューできる
- 空間 → リング → 写真 の3層構成。クリック／VRトリガー1回で1層ずつ奥へ進み、「戻る」で1層ずつ手前へ戻る
- 記憶を押すと、接近の開始と同時に小球がユーザーを中心に前後左右へ広がる。約1.1秒の接近中も中心が視点位置に追従し、接近が終わると泡の展開も完了する。到着後にもう一度外へ広がったり、視点から離れたりせず、約0.6m（もともと近い場合はその近い距離）の配置を維持して小さく揺れる。小球の大きさも引き継ぎ、押した写真を正面にする。7個を基本に、写真が多い場合は全写真分を用意する
- かけらを押すと、その写真が視界を包む曲面スクリーンに広がる（横長の写真ほど大きく回り込む）
- アップロードした記憶やみんなの空間に共有された記憶にも、同じ操作を適用
- Cloud Domeのグリッド版（`public/exports/cloud-dome-grid.glb`）を背景空間として常時表示し、水面アニメーションを再生。背景は深度を書き込まず、ユーザーの周囲に広がる泡や写真を壁面で隠さない
- 左上に WebXR 診断情報（navigator.xr, immersive-vr / immersive-ar 対応状況）

## 使い方

```sh
pnpm install
pnpm dev
```

WebXR は HTTPS（または localhost）でのみ動作します。

## 操作と検証

- 記憶の作成：「写真を選ぶ」（または空間へのドロップ）→ 公開前のモーダルで写真を大きく確認・追加・削除、任意のタイトルを入力 →「公開する」。最初の入力UIの大きさは維持。JPEG・PNG・WebP、1つの記憶につき合計10枚まで。同じ写真の重複選択は除外。公開を押すまで写真は送信せず、空間にも追加しない。公開に失敗した場合は写真とタイトルを残して再試行できる。閉じる・Escでは破棄前に確認し、公開中は編集・破棄・二重送信を防ぐ。公開後の写真追加は対象外
- 空間：ポインターや VR コントローラーのレイを記憶（中心の球体または周りの円）に重ねると、記憶が約0.85秒で自然に分裂して小〜中サイズの7個に広がり、5cm手前に寄って全体が1.08倍になる。下にタイトルと「N枚の写真」のラベルが出る（タイトルのない記憶は「記憶」）。VRではレイが対象を指していないとき、頭の向きによる注視でも同じ反応になる。分散した隙間で選択が途切れないよう、選択中のまとまり全体で判定する。注視だけでは記憶に入らず、クリック／トリガーで入る。タッチ端末にはホバーはない
- 記憶を1回押す（タップ／トリガー）と、Webでは約1.1秒かけて近づく動きと、小球がユーザーを包む動きを同時に行う。接近完了後の追加の分散や遠ざかる動きはない。接近中に大きな球へ戻したり、別の泡に突然切り替えたりしない。VRでは視点を強制移動せず、実際の頭の位置の周囲へ泡だけを広げる。何もない場所を押しても何も起きない
- 近づいている間：画面下部の「戻る」ボタンまたは Esc で中止でき、展開中の泡が集まって融合するのと同時に元の位置へ戻る。ドラッグで見回せる（動いた分だけ視線の向きに加わる）。クリック・歩行・ホイールは受け付けない
- そのほかの移動中（リングが開く・閉じる、元の位置へ戻る）：ドラッグで見回せる。クリック・歩行・ホイール・Esc は受け付けない
- リング：かけらを1回押す（クリック／タップ／トリガー）と、すぐに写真が曲面スクリーンに開く。VRではレイまたは視線を合わせたかけらが、押した瞬間に開く。ポインター・レイ・視線を重ねたかけらは内側に寄って大きくなり、下に記憶のタイトルと「写真 n/N」のラベルが出る。下部の説明は「写真を選ぶと、記憶にひたれます」の1行だけ
- VRのリングでは、かけらを指していない所でつまんだ（トリガーを押した）まま手を左右に動かすと、リング全体が手についてくるように回る
- リングを閉じる「戻る」は常に表示：Web（スマートフォンを含む）では正面の写真のすぐ下（画面の高さの約76%）中央の固定ボタン（Esc と同じ）、VR セッション中だけ正面の写真のすぐ下（目の高さ−0.35m、正面0.7m）に浮かぶ 3D ボタンを表示する。3D ボタンは大きく振り向くと正面へ回り込み、かけらを選ばずにレイで押してリングを閉じられる。閉じるとリングが球体に戻り、来たときと同じ動きで元の位置へ戻る
- リングでは見回し（ドラッグ／頭の向き）だけができ、WASD・ホイール・ピンチでは移動しない。歩けるのは空間の層だけ
- 写真：リングへ戻らずに同じ記憶の写真を前後へ切り替えられる。順番は記憶の写真の並び（ファイルパス順）で、最初と最後で止まり、ループしない
  - Web では画面左右端の固定矢印ボタンと ← / → キー（修飾キーなし。押しっぱなしの連続入力は無視）。VR セッション中だけ曲面スクリーン左右に 3D 矢印を表示し、トリガーで操作する
  - タッチ・ペン：0.4 秒以内に横へ 50px 以上払うと、左へ払えば次、右へ払えば前の写真。マウスのドラッグは今までどおり見回し
  - VR：サムスティックを左右に倒すと1枚ずつ切り替わる。中央付近へ戻すまで次の入力は受け付けない
  - 最初・最後の写真では、その向きの矢印を薄く表示し押せなくする
  - 切り替えは、今の写真が約 0.3 秒でフェードアウトし、次の写真が中央から約 0.6 秒で広がる。高解像度の写真が届いていなければ、読み込みを最大 1.5 秒待ってからプレビューで先に開き、届いた時点でその場で差し替える。切り替え中の連続入力は最後の行き先にまとめる
  - 下部のヒントは「← → で写真を切り替え · 戻るでリングへ」
- 写真から戻る：Web では画面下部中央の固定「戻る」または Esc、VR では正面下の 3D「戻る」タブでリングへ。Web の写真ヒントは固定ボタンの上に置き、重ならない。最後に見ていた写真のかけらが正面に来るよう、リングが約 0.6 秒で回り込む
- 現在地：上部中央（ロゴと VR チップの間。幅 760px 以下ではその下の行）にパンくずを表示する。空間では表示せず、記憶では「空間 › {タイトル}」、写真では「空間 › {タイトル} › 写真 {n}/{N}」。押した時点（記憶へ近づき始めたとき、写真が開き始めたとき）と「戻る」を押した時点で切り替わり、写真を送ると n がすぐに変わる。表示専用で、押しても何も起きない
- 文言：層を移る操作の名前は「戻る」だけ（画面下部のボタン、3D タブ、Esc のどれも「戻る」。ボタンのアクセシブルネームも「戻る」）。英語のラベルは使わず、ロゴの memoria だけを残す。three.js の VRButton の表示（ENTER VR など）も日本語に置き換える（「VRで見る」「VRを終了」「VR非対応」など）
- 空間のフッターの案内は「球体を押すと、記憶のなかへ · ドラッグで見回し、WASD・ホイール・ピンチで歩けます · 写真はみんなの空間に公開されます」
- Web ではロゴ・VRチップ・通知を全層で表示。下部の入力欄・接近中の「戻る」・ツールバー・写真のヒント・上部のパンくずは層に応じてフェードで切り替わる。Web の操作・案内は画面固定 UI に統一し、3D のボタン・案内は表示も選択もできない。VR セッション中は画面固定 UI を非表示かつ操作不可にし、3D の操作・案内だけを使う。球体・写真・タイトルラベルはどちらでも表示する
- 訪問時の案内：共有された記憶の件数や過去の訪問履歴に関係なく、ページを開くたび（再読み込みを含む）に「見る：球体にカーソルを合わせる」「入る：押すと記憶のなかへ」「戻る：いつでも1つ前に戻れる」を中央のモーダルに表示する。背景を暗くぼかし、表示中は背景の操作を止める。「はじめる」または Esc で閉じる（VR などで球体に入った場合も同じ）。そのページ内で操作している間は再表示しない。localStorage は使用せず、以前の保存済みフラグも参照しない
- 通知（トースト）は 3 秒表示して消える
- リングを開いている間、ほかの記憶は小さくなって退き、閉じると元に戻る
- OS の「視差効果を減らす」設定（`prefers-reduced-motion`）が有効な場合は即時移動します
- VR では視点をアニメーション移動せず、実際の頭の位置を中心にリングを開きます
- VR の案内パネル：没入型 VR では HTML の画面が見えないため、パンくず・いまの層の案内・通知を 1 枚の 3D パネルに映す。パネルは視点の正面 1.2m、目の高さ −0.35m に浮かんでこちらを向き、頭の動きに毎フレーム 0.1 の割合（60fps 換算。90Hz などでも同じ速さ）で追従する。VR に入った瞬間は正面に置き、VR の外では表示しない。レイの当たり判定はなく、リングや曲面スクリーンより手前に描く
  - 1 行目はパンくず（空間では表示せず、記憶では「空間 › {タイトル}」、写真では「空間 › {タイトル} › 写真 {n}/{N}」。長いタイトルは末尾を「…」で省く）
  - 案内はコントローラー向けの文言：空間「球体にレイを向けてトリガーを引くと、記憶のなかへ」「写真はみんなの空間に公開されます」、リング「写真をトリガーで選ぶと、記憶にひたれます」「足元の「戻る」で空間へ」、写真「スティックか左右の矢印で写真を切り替え」「画面下の「戻る」でリングへ」、層を移る間は「移動中…」
  - 空間では、フッターと同じ読み込み中・保存中・エラーの表示を案内の下に添える
  - 通知はパネルの上に Web と同じ色の帯で 3 秒表示し、フェードで消える
- VR の開始・終了：どちらの時点でも、開いている写真とリングは閉じるアニメーションなしで即座に閉じ、空間の層から始め直す。記憶へ近づいていた（または近づいた後だった）場合は、近づく前の位置に戻る。VR を終えると、VR に入る前の Web の視点（位置・向き・画角）に戻る。切り替え前のキー押下やドラッグは持ち越さない
- VR の球体配置：開始後の最初の有効な頭の姿勢を待ち、中央の球体を目の高さの水平正面 1.5m に配置する。上下の傾きや首の傾きは無視し、水平方向だけを使う。他の球体も間隔・段差を保って一緒に移動する（小さな浮遊アニメーションは維持）。配置はセッション開始ごとに一度だけで、その後の頭の移動・回転には追従しない。VR 中に読み込まれた記憶にも同じ配置を使い、終了すると Web の配置に戻す

```sh
pnpm build
pnpm exec tsc --noEmit
node --experimental-strip-types --test tests/photoBrowse.test.mjs tests/sphereJourney.test.mjs tests/sceneGuide.test.mjs
node --experimental-strip-types --test tests/memoryDraft.test.mjs
node --experimental-strip-types --test tests/vrMemoryLayout.test.mjs
node --experimental-strip-types --test tests/memoryMaterial.test.mjs
node --experimental-strip-types --test tests/sphereSatellites.test.mjs
node --experimental-strip-types --test tests/sphereFusion.test.mjs
node --experimental-strip-types --test tests/memoryRing.test.mjs
node --experimental-strip-types --test tests/bubbleMembranes.test.mjs
```

`tests/photoBrowse.test.mjs` は写真の前後移動（端で止まる）、矢印の有効状態、スワイプ判定、サムスティックのしきい値を検証します。
`tests/sceneGuide.test.mjs` はパンくずの文言、VR の案内文（Web 専用の操作名を含まないこと）、通知の 3 秒表示、パネル追従のフレームレート補正を検証します。
`tests/vrMemoryLayout.test.mjs` は座位・立位の高さと上下の傾きに依存しない水平配置、配置後の空間固定、新しい記憶への適用、終了・再入場時の復元を検証します。
`tests/memoryMaterial.test.mjs` は記憶ごとの色分け、IDによる色の固定、薄膜干渉・透明感・ハイライト、膜の時間変化と記憶ごとに独立したリングのフェードを検証します。
`tests/sphereSatellites.test.mjs` は通常時5個・注視中7個の構成、初期サイズのランダム化と最大の小球の0.6倍縮小、小〜中サイズへの分散と復元、等間隔に偏らないランダム配置、小球ごとの漂いと膜の小さな変形、ラベルの余白、フレームごとに再配置されないこと、リング開閉後の復元を検証します。ブラウザー回帰テストではホバーとVRの頭の向きによる注視で大きな泡がなくなること、隙間での選択維持、注視解除での復元も検証します。
`tests/sphereFusion.test.mjs` は小球間に連続した膜ができること、分離で膜のくびれが切れ、接近で再融合すること、非表示の小球が古い形状を残さないことを検証します。ブラウザーでは分裂・融合の途中に実際の連続面が描かれることも記録して確認します。
`tests/memoryRing.test.mjs` はプレビューの位置・大きさを引き継ぐ連続した展開、目の位置を囲む前後左右・上下・奥行きのある小球配置、全写真の保持、戻るときの集まりと融合を検証します。
`tests/bubbleMembranes.test.mjs` は初期状態でも一枚の膜になること、3個以上の連鎖した重なり、離れた複数グループの独立した膜、再接触時の融合、写真・選択形状・マテリアルの復元を検証します。

ブラウザー回帰テストは、既存プレビューと remote debugging（既定ポート `9222`）を有効にした Chromium に対して実行します。共有メモリーAPIはテスト内で差し替え、実際の保存データは変更しません。
最後に、ヘッドセットなしで VR セッションを擬似的に開始し（頭の姿勢とコントローラーのレイをテストから与える）、VR の中だけで記憶に入る・写真を送る・戻るを行えること、案内パネルの位置・文言・追従、VR の開始・終了でリングと写真が閉じて視点が戻ることを確認します。

```sh
node tests/sphereJourney.browser.mjs
node tests/memoryDraft.browser.mjs
```

`MEMORIA_URL`（既定 `http://localhost:3000`）、`CDP_URL`（既定 `http://localhost:9222`）で接続先を変更できます。

## 「場所の思い出」タブ・匿名認証の現在地

起動時は泡0個の「場所の思い出」タブを表示し、既存の画面は「デモモデル」から開きます。位置情報保存の管理者設定・RLS検証・カメラとARの仕様は [設定手順](docs/private-location-setup.md) を参照してください。匿名認証と専用テーブルの設定が完了するまで実DBへの位置情報保存は有効になりません。

## 写真を場所に残すカメラ版

撮影・位置付き公開確認・周辺50mの探索・写真枚数分の円周表示を追加しました。ロゴとUIはデモの素材を共用します。[場所付き思い出の設定手順](docs/place-memories-setup.md) に従い、匿名認証・追加SQL・新しいEdge Functionを反映してください。未反映時に成功を装った表示や疑似投稿は行いません。

## Supabase接続先の変更

現在の対象は `niaopqpzpwrfhfwzllzs` です。[新プロジェクトの接続手順](docs/supabase-project-setup.md) に従い、公開キー・匿名認証・SQL・Edge Functionを設定してください。旧プロジェクトの共有APIへの通信は停止し、デモは同梱写真で表示します。場所付き投稿は「場所の思い出」タブから利用します。

## WebとWebXRのページ

通常Webはカメラ映像・環境モデルなし。周囲の実環境はWebXR ARで表示します。「場所の思い出」と「自分の思い出」を分離し、本人の写真もデモ共通の融合する泡と円周で表示します。[ページの仕様と確認方法](docs/web-and-xr-views.md) を参照してください。
